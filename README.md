# 🧩 Java Swing Sudoku Game

A functional and interactive 9x9 Sudoku game built with **Java Swing**. This project features a custom graphical user interface (GUI) designed for grid-based puzzle mechanics, mistake tracking, and responsive layout management.

---

## ✨ Features

- **Classic 9x9 Grid Design:** Custom layout built using Java Swing components (`JFrame`, `JPanel`, `JButton`, `JLabel`).
- **Thick Grid Borders:** Clear visual separation for 3x3 Sudoku sub-grids using custom matte borders.
- **Mistake Counter:** Real-time error tracking that increments whenever an incorrect digit is placed.
- **Reset Button:** Easily clear user entries and reset the error counter without restarting the application.
- **Victory Detection:** Automatic win state check with a congratulations popup (`JOptionPane`) upon completing the puzzle correctly.
- **Game Window Control:** Fixed window sizing (`setResizable(false)`) and screen centering (`setLocationRelativeTo(null)`).

---

## 🛠️ Built With

- **Language:** Java
- **GUI Framework:** Java Swing / AWT
